Amazon VPC

Virtual Private Cloud — rede virtual para recursos da AWS.

O que é?

O Amazon VPC (Virtual Private Cloud) é um serviço de rede que permite criar uma rede virtual na AWS para organizar e controlar a comunicação dos recursos.

Para que serve?

Uma VPC pode utilizar componentes como sub-redes e gateways. A segurança da rede também pode envolver ACLs de rede e grupos de segurança.

Principais características

  • Permite organizar recursos em uma rede virtual.
  • Utiliza sub-redes para estruturar a rede.
  • Pode utilizar gateways para conectividade.
  • Possui recursos relacionados à segurança de rede.

Exemplos de uso

  • Organizar recursos de uma aplicação em uma rede virtual.
  • Separar recursos de acordo com diferentes necessidades de rede.
  • Controlar o acesso e a comunicação entre recursos.
  • Criar ambientes de rede para aplicações hospedadas na AWS.

Relação com o Cloud Practitioner

No Cloud Practitioner, é importante identificar componentes de uma VPC, como sub-redes e gateways, e compreender aspectos de segurança, como ACLs de rede e grupos de segurança.
