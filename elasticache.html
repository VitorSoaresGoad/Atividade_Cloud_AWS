Amazon ElastiCache

Banco de dados baseado em memória para aplicações.

O que é?

O Amazon ElastiCache é um serviço de banco de dados baseado em memória. Ele é usado para disponibilizar dados em memória para aplicações que precisam de acesso rápido a informações armazenadas.

Para que serve?

Por utilizar armazenamento em memória, o serviço é adequado a cenários em que o acesso rápido aos dados é importante. O Cloud Practitioner classifica o ElastiCache entre os bancos de dados baseados em memória.

Principais características

  • É classificado como serviço de Banco de Dados.
  • É baseado em memória.
  • Pode ser utilizado para melhorar o acesso a dados frequentemente utilizados.
  • Faz parte dos serviços de banco de dados abordados no Cloud Practitioner.

Exemplos de uso

  • Armazenar dados temporariamente em memória.
  • Acelerar o acesso a dados frequentemente consultados.
  • Apoiar aplicações que precisam de respostas rápidas.
  • Reduzir a necessidade de buscar repetidamente determinados dados em uma fonte mais lenta.

Relação com o Cloud Practitioner

O guia do Cloud Practitioner apresenta o Amazon ElastiCache como exemplo de banco de dados baseado em memória e o inclui entre os serviços de banco de dados dentro do escopo do exame.
