AWS WAF

Web Application Firewall — recurso de proteção para aplicações web.

O que é?

O AWS WAF é um serviço de segurança da AWS voltado à proteção de aplicações web. Ele faz parte dos recursos de segurança que aparecem no conteúdo do Cloud Practitioner.

Para que serve?

O WAF ajuda a controlar e filtrar solicitações direcionadas a aplicações web, permitindo estabelecer regras para lidar com tráfego que corresponda a determinados critérios.

Principais características

  • É um serviço de segurança da AWS.
  • É voltado para aplicações web.
  • Permite trabalhar com regras de filtragem de solicitações.
  • Pode fazer parte de uma estratégia de proteção de aplicações.

Exemplos de uso

  • Ajudar a proteger uma aplicação web.
  • Controlar solicitações recebidas por uma aplicação.
  • Aplicar regras de segurança ao tráfego web.
  • Complementar outros recursos de segurança da AWS.

Relação com o Cloud Practitioner

O guia do exame cita explicitamente o AWS WAF entre os serviços e recursos de segurança da AWS que o candidato deve conhecer.
